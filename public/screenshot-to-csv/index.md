# Screenshot table to CSV

AI Converter pulls table-like data from screenshots and image PDFs into spreadsheet-ready CSV. Upload the file, check sample rows free, then unlock the full CSV only when the preview looks useful.

## Workflow

1. Upload a screenshot or image PDF as PNG, JPG, JPEG, WEBP, or PDF (up to 50 MB).
2. Review sample rows free before payment.
3. Unlock the full CSV if the preview is usable.
4. Download rows with inferred columns (Column 1, Column 2, Column 3, etc.) matching the detected table structure.

## Output shape

Screenshot exports are one row per detected table row. Columns are inferred from the table header or structure and use generic labels (Column 1, Column 2, …) unless headers are clearly readable. Merged cells, multi-line cells, or nested tables may not extract cleanly.

## Limits

Only PNG, JPG, JPEG, WEBP, and PDF files are accepted, up to 50 MB each. Jobs stop without an export when no table structure can be detected or extraction confidence is too low. Blurry, low-resolution, angled, or partially cut-off screenshots may fail. Screenshot conversion is a beta module and AI Converter does not claim support for every table layout, language, or image quality.

The export should be compared with the original screenshot before important use.
