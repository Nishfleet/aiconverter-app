# Formats page — `/formats/`

Public catalogue of every conversion route the live app is allowed to
offer. The static HTML (in `dist/formats/index.html` after `npm run build`)
is a server-rendered, no-JS view of the same `src/data/converters.json`
list the React `<FormatsPage>` component reads; the React app replaces
it with a searchable, category-filtered grid once it hydrates.

## How users reach it

Open `https://aiconverter.app/formats/` (or `http://127.0.0.1:4180/formats/`
for the local harness), or follow the `formats` link in the footer /
homepage ticker.

## How to drive it (local)

1. `GET /formats/` → expect 200. The pre-rendered HTML must contain:
   - `<title>Formats - AI Converter conversion options</title>`.
   - `<link rel="canonical" href="https://aiconverter.app/formats/" />`.
   - `<h1>Every route the live app is allowed to offer.</h1>`.
   - The four top-level `<h2>` section headings exactly:
     - `Bank statement exports`
     - `Receipts, invoices, screenshots`
     - `Markdown and common document swaps`
     - `Images, audio, video, archives`
   - The `Availability is not a blanket promise.` and
     `Use the preview as your quality gate.` footers.

```bash
curl -fsS http://127.0.0.1:4180/formats/ -o /tmp/verify-aiconverter/formats.html
grep -F 'Every route the live app is allowed to offer.' /tmp/verify-aiconverter/formats.html
grep -F 'Bank statement exports' /tmp/verify-aiconverter/formats.html
grep -F 'Receipts, invoices, screenshots' /tmp/verify-aiconverter/formats.html
grep -F 'Markdown and common document swaps' /tmp/verify-aiconverter/formats.html
grep -F 'Images, audio, video, archives' /tmp/verify-aiconverter/formats.html
grep -F 'Availability is not a blanket promise.' /tmp/verify-aiconverter/formats.html
grep -F 'Use the preview as your quality gate.' /tmp/verify-aiconverter/formats.html
```

## How to drive it (live, for the search/filter UI)

1. `https://aiconverter.app/formats/` → expect 200, same shape as above.
2. The React `<FormatsPage>` reads `data.converters` from
   `src/data/converters.json` and renders a category-tab grid plus a
   `<input type="search">` filter. Use Playwright (this repo's
   `playwright` is pinned to `1.62.1`):
   - Click the `Images` tab → only the image-format / raster-vector /
     screenshot-code cards remain.
   - Type `quickbooks` into the search input → only the `Bank statement
     PDF to QuickBooks CSV` card remains.
   - Click `Clear search and filters` → the full grid returns.

## What proves success

- HTTP 200.
- All five `<h1>` / `<h2>` strings above are present in the pre-rendered
  HTML.
- `rel="canonical"` is `https://aiconverter.app/formats/`, not the
  loopback origin.
- The static page never advertises a route the live app does not offer
  (the copy in `dist/formats/index.html` is generated by
  `scripts/build-sitemap.mjs` from the same `converters.json` the React
  app reads, so a drift between the two surfaces is a build bug — file
  it as a new issue, do not paper over it in this PR).
